## What Grok Bot is for

Desktop assistants inside Cursor that can:

- Keep GitHub organised (reviews, hygiene, indexes)
- Draft and maintain shared agent notes
- Run standing checks (routines) and ping when something needs a human decision
- Help move work between Grok Heavy (research) and Grok Build (implementation)

They are **not** a replacement for Grok Build’s coding loop; they coordinate, monitor, and do ops-shaped work.
